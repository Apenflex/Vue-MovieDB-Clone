# Шрифти

Покладіть сюди файли шрифту **Source Sans 3** (з `mixins.scss`):

- `SourceSans3-Regular.woff2` (і за бажанням .ttf, .eot)
- `SourceSans3-SemiBold.woff2` (і за бажанням .ttf, .eot)
- `SourceSans3-Bold.woff2` (і за бажанням .ttf, .eot)

Після цього шлях `url('../fonts/...')` у стилях буде коректно знаходити файли.
